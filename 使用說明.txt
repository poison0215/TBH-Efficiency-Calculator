========================================
 TBH 塔斯克巴·英雄 效率計算機
========================================

【如何啟動】
雙擊「TBH效率計算機.exe」即可，不需要安裝 Python。
（Tesseract OCR 已內含在資料夾裡，不用另外安裝）

【第一次使用】
1. 先開啟遊戲 TaskBarHero
2. 開啟本程式 → 切到「區域設定」分頁
3. 分別點「選取區域」，在遊戲畫面上框出「金幣」和「經驗」數字的位置
   - 經驗請框完整的「目前經驗 / 升級需求」整段
4. 框好後下方會即時顯示 OCR 讀到的數值，確認讀得正確
5. 回「即時監控」分頁 → 按「開始監控」

【即時監控】
- 金幣、經驗的每秒/分鐘/小時速率（全程累計平均）
- 升級進度條、預計升級時間
- 可設定「自動保存：監測 N 分鐘後自動保存並停止」

【關卡比較】
- 監控一段時間後，輸入關卡名稱 → 按「保存至比較表」
- 到「關卡比較」分頁比較哪關效率高
- 點欄位標題可排序

========================================
【說明】
只用畫面 OCR 截圖讀取數值，不讀取遊戲記憶體、
不做任何自動點擊或修改，純屬外部觀察的效率計算工具。
監控時請保持遊戲畫面可見。
========================================



========================================
 TBH Task Bar Hero - Efficiency Calculator
========================================

[How to Launch]
Double-click "TBH效率計算機.exe". No Python installation needed.
(Tesseract OCR is bundled in the folder, no separate install required.)

[First-time Setup]
1. Launch the game TaskBarHero first
2. Open this app -> go to the "區域設定" (Region Setup) tab
3. Click "選取區域" (Select Region) and drag a box over the
   "Gold" and "EXP" numbers on the game screen
   - For EXP, box the full "current EXP / required EXP" text
4. The OCR-read value shows below in real time; confirm it reads correctly
5. Go back to the "即時監控" (Live Monitor) tab -> click "開始監控" (Start)

[Live Monitor]
- Gold & EXP rate per second / minute / hour (whole-session average)
- Level-up progress bar and estimated time to level up
- Optional auto-save: automatically save & stop after N minutes

[Stage Comparison]
- After monitoring a while, enter a stage name -> "保存至比較表" (Save)
- Compare which stage is most efficient in the "關卡比較" tab
- Click column headers to sort

========================================
[Notes]
This version only reads values via on-screen OCR. It does NOT
read game memory, does NOT auto-click, and makes NO modifications -
it is purely an external observation / efficiency calculator tool.
Keep the game screen visible while monitoring.
